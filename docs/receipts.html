The thanks trap
"Thanks" keeps the line no tool on the acknowledgement "Next" fires tell_joke
Down an 8 kHz line, "next" and "thanks" are nearly the same word, and the costs are asymmetric: a wrong "next" costs one joke, a wrong "thanks" costs the whole call. So thanks never hangs up — the acknowledgement gets a beat and a door, and the run continues.

"Thanks." — the trap. An acknowledgement is not a request, and it is never a hang-up.
